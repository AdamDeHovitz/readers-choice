# Verification: chore: serve production at readers-choice.dehovitz.com

## Change

Production is served at https://readers-choice.dehovitz.com. The old readers-choice.vercel.app address permanently redirects there (except the keep-alive cron path), and docs and the privacy page name the new domain.

## Checks

- `npm run lint`: clean
- `npm run typecheck`: clean
- The redirect is configuration only (`apps/web/vercel.json`). It matches the `readers-choice.vercel.app` host, so it can only be observed on production after merge. The post-merge results are recorded below.
