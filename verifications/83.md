# Verification: fix: 404 malformed club and meeting ids instead of a 500

## Change

A club or meeting URL with a malformed id (e.g. `/book-clubs/not-a-uuid/themes`) now shows an app-styled "Page not found" page with a 404, instead of crashing with a 500. Well-formed unknown ids behave as before.

## Checks

- `npm run lint`: clean
- `npm run typecheck`: clean
- `npm run test:run`: 41 files, 419 passed (main: 40 files, 418). New: `packages/contract/schemas.test.ts`, which checks `isRowId` agrees with `rowId` on 10 values.
- `npm run build` (dummy env): compiled; `○ /_not-found` is now the app's page.
- `PORT=3200 npx playwright test`: 15 passed, including the new `not-found.spec.ts`.
