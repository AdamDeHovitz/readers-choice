# Verification: feat: operation layer, piloted on themes

## Change

Theme mutations and the theme-suggestions read are now operations: a contract in `contract/themes.ts` (zod input, output type), an implementation in `server/operations/themes.ts`, and a one-line `serverAction(...)` export in `app/actions/themes.ts`. Members can still suggest, upvote and delete themes as before, and the meeting form still autocompletes theme names. The server actions still reject non-members, signed-out callers and malformed input, now with schema errors for bad shapes. Theme actions now take one object argument.
