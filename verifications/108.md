# Verification: feat: admins can see the live vote tally during voting

## Change

Club admins can open **See current results** on a meeting while voting is open and see the Hybrid IRV tally (in both the approval and ranked ballot views). Members can't: the dropdown isn't rendered for them, and `calculateMeetingResults` (behind the `getMeetingResults` action) now returns null for non-admins until voting closes. Finalized and voting-closed results are unchanged apart from copy.

## Checks

- `npm run lint`: clean
- `npm run format:check`: clean
- `npm run typecheck`: clean
- `npm run test:run`: 53 files, 499 tests passed, including the new `apps/web/server/voting.test.ts` (member hidden while open, admin sees live tally, member sees results once closed, non-member hidden)
- `npm run build` (dummy env): succeeded
