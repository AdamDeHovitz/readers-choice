# Verification: refactor: npm workspaces monorepo (apps/web, packages/core, packages/contract)

## Change

The repo is an npm workspaces monorepo. The website lives in `apps/web`, and the shared code is `@readers-choice/core` (was `lib/`) and `@readers-choice/contract` (was `contract/`). Commands still run from the root. Nothing a member sees should change.

## Checks

- `rm -rf node_modules && npm install`: workspace links created (`node_modules/@readers-choice/{web,core,contract}` → `apps/web`, `packages/core`, `packages/contract`). The lockfile diff only adds the three workspace entries; no dependency versions changed.
- `npm run lint`: clean
- `npm run typecheck` (root scripts, `apps/web`, `packages/core`, `packages/contract`): clean. Its first run failed on `packages/core/open-library.ts` and `packages/core/libraries/overdrive.ts`, which passed Next's `next: { revalidate }` fetch option that only type-checked through Next's globals.
