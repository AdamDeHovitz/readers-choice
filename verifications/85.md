# Verification: fix: self-host the web fonts so builds don't depend on Google Fonts

## Change

The site's two typefaces are served from our own files instead of being downloaded from Google Fonts at build time, so a Vercel build can no longer fail because of the URL format Google happens to return. The site looks the same.

## Checks

- `npm run lint`: clean
- `npm run typecheck`: clean
- Clean build (`rm -rf apps/web/.next`, then `npm run build` with `NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321`): compiled. `grep -rl "fonts.gstatic\|fonts.googleapis" apps/web/.next/static apps/web/.next/server` finds nothing.
- Files: `apps/web/app/fonts/{inria-serif,playfair-display}-latin-{400,700}-normal.woff2` (21–23 KB each) and both OFL `LICENSE` files, from `@fontsource/inria-serif@5.3.0` and `@fontsource/playfair-display@5.3.0`.

### Fonts load from our server

Production build served with `scripts/dev-local.sh --prebuilt` on :3201, `/login` in headless Chromium:

```
font requests: ["localhost:3201/…/inria_serif_latin_400_normal-s.p.bfe70815.woff2","localhost:3201/…/inria_serif_latin_700_normal-s.p.265ba564.woff2","localhost:3201/…/playfair_display_latin_400_normal-s.p.9b5ebe0f.woff2","localhost:3201/…/playfair_display_latin_700_normal-s.p.2b4c1db0.woff2"]
loaded faces: ["inriaSerif 400","inriaSerif 700","playfairDisplay 400"]
computed: {"body":"inriaSerif, \"inriaSerif Fallback\", Georgia, serif, …","h1":"playfairDisplay, \"playfairDisplay Fallback\", Georgia, serif, …"}
```

No requests go to Google. The body uses Inria Serif and the h1 uses Playfair Display, as on production. Playfair 700 is preloaded but unused on `/login`, so it isn't in "loaded".

## Not verified

- A pixel comparison against production. The files are the same Google Fonts latin subsets that `next/font/google` downloaded, but I compared computed font families, not screenshots.
- Non-latin characters (accented names beyond Latin-1, other scripts) fall back to Georgia. `next/font/google` was already limited to the `latin` subset, so this is unchanged.

## Harness gaps

- CI builds on GitHub runners, where Google Fonts answered normally, so CI passed while Vercel failed. Self-hosting removes that difference.
