# Verification: break vote ties with whole ballots, keeping past meetings on their rules

## Change

New meetings break ties (for lowest support, and between books that both reach a majority) with every ballot from both pools: head-to-head record among the tied books, then how many ballots list the book, then random. Every meeting that already has votes keeps the old rules through `meetings.tally_rules = 1`, so no past result changes.

### Rules 1 reproduce the deployed algorithm exactly

Script (not committed) runs main's `packages/core/voting-algorithm.ts` and this branch's `runHybridIRV(..., rules = 1)` on the same input and compares every round (support, elimination and reason, transfers, exhausted voters, threshold, winner). Inputs: all 11 production meetings with votes (pulled read-only, ids anonymized order-preserving), each with its real seed plus seeds 0–499, and 50,000 random tie-heavy elections (1–8 books, 0–6 voters per pool):

```

fuzz: 50000 elections, 0 differences
```
