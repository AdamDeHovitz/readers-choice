# Verification: Mobile-first UI refresh and app shell

## Change

Every page now sits in one app shell rendered by layouts: a sage top bar, a bottom tab bar on phones (inline tabs from `md`), club tabs Home / Schedule / Rankings / Themes / Members, and meetings under Schedule. URLs are unchanged. ## Behavior

### App shell and navigation

- `e2e/navigation.spec.ts` (as bob): from My clubs, opening Seed Club marks Home `aria-current="page"`. Tapping Schedule, Rankings, Themes and Members each lands on a page whose `h1` is that name, with that tab current. Rankings → "Club ranking" goes to `/global-rankings` with Rankings still current. This spec guards the tab set and active-state logic in `components/shell/nav-tabs.tsx`.
- Same spec: `/meetings/44444444-0000-4000-8000-000000000003` marks Schedule current, and the top bar's back chevron (`banner` → link "Schedule") lands on `/book-clubs/…/schedule`.
- Same spec: Settings tab → "Sign out" lands on `/`.
- Existing spec still passes: dave opening Seed Club's nominating meeting is redirected to `/dashboard`, so the new meeting layout doesn't leak the club shell to non-members.
- As alice at 390×844, visited 15 pages (landing, login, dashboard, club home, schedule, both rankings, themes, members, all four seeded meetings, settings, browse): no `pageerror`s, and no response ≥ 400. `/manifest.webmanifest` returned 200 while signed out (the proxy matcher now skips it, `/icon.svg` and `/apple-icon`).
- At 360px wide, `document.documentElement.scrollWidth` was ≤ 360 on `/dashboard`, `/browse`, `/settings`, themes, members, rankings, and the voting-closed and finalized meetings: no horizontal scroll.
- At 1280px, the club tabs render in the top bar and the bottom bar is hidden.

## Harness gaps

- Seed books had no `cover_url`, so covers couldn't be seen locally; fixed in this PR's `seed.sql`. Seed pages now load images from openlibrary.org, so they need internet access.
- `npm run build` fails in a checkout where `npm run dev:local` is running, because of stale `.next/dev/types` from moved routes. Builds had to run in an isolated copy.
- No e2e spec covers nominating, because search hits Open Library live and specs only read seed data.
