# Verification: feat: themes screen read model (themes.list)

## Change

The Themes page loads through one members-only query operation, `themes.list`, whose output schema is the screen's DTO and includes a per-theme `canDelete` computed with the same rule `deleteTheme` enforces. Members see delete buttons only where deleting would succeed. Non-members are sent to the club page. The same data is available to mobile at `POST /api/v1/themes.list`.
